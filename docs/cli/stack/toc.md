# docker stack — TOC

Manage Swarm stacks.

- [Overview](./overview.md)

## Subcommands

| Command | Description |
|---|---|
| [config](./config/overview.md) | Outputs the final config file, after doing merges and interpolations |
| [deploy](./deploy/overview.md) | Deploy a new stack or update an existing stack |
| [ls](./ls/overview.md) | List stacks |
| [ps](./ps/overview.md) | List the tasks in the stack |
| [rm](./rm/overview.md) | Remove one or more stacks |
| [services](./services/overview.md) | List the services in the stack |
