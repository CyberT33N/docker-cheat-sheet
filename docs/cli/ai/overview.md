# docker ai

Docker AI Agent - Ask Gordon.

> `docker ai` is a Docker CLI plugin. Run `docker ai` to start a conversation thread, or pass a single question, e.g. `docker ai "How do I run redis?"`.

## Usage

```text
docker ai [OPTIONS] COMMAND
```

## Options

| Option | Description |
|---|---|
| `-C, --working-dir string` | Sets the working directory for the command |
