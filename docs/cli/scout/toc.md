# docker scout — TOC

Command line tool for Docker Scout.

- [Overview](./overview.md)

## Subcommands

| Command | Description |
|---|---|
| [compare](./compare/overview.md) | Compare two images and display differences (experimental) |
| [config](./config/overview.md) | Manage Docker Scout configuration |
| [cves](./cves/overview.md) | Display CVEs identified in a software artifact |
| [enroll](./enroll/overview.md) | Enroll an organization with Docker Scout |
| [environment](./environment/overview.md) | Manage environments (experimental) |
| [help](./help/overview.md) | Display information about the available commands |
| [policy](./policy/overview.md) | Evaluate local Rego policies against an image and display the results (experimental) |
| [push](./push/overview.md) | Push an image or image index to Docker Scout |
| [quickview](./quickview/overview.md) | Quick overview of an image |
| [recommendations](./recommendations/overview.md) | Display available base image updates and remediation recommendations |
| [version](./version/overview.md) | Show Docker Scout version information |
| [watch](./watch/overview.md) | Watch repositories in a registry and push images and indexes to Docker Scout |

## Management command groups

| Command | Description |
|---|---|
