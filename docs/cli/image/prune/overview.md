# docker image prune

Remove unused images.

## Usage

```text
docker image prune [OPTIONS]
```

## Options

| Option | Description |
|---|---|
| `-a, --all` | Remove all unused images, not just dangling ones |
| `--filter filter` | Provide filter values (e.g. "until=<timestamp>") |
| `-f, --force` | Do not prompt for confirmation |
