# docker image ls

List images.

## Usage

```text
docker image ls [OPTIONS] [REPOSITORY[:TAG]]
```

## Aliases

- `docker images`
- `docker image list`

## Options

Identical to the canonical command. See [docker images](../../../images/overview.md) for the complete option reference.

## Documented examples

Show existing images ([reference](https://docs.docker.com/engine/reference/commandline/image/)):

```bash
sudo docker image -ls
```
