# docker image — TOC

Manage images.

- [Overview](./overview.md)

## Subcommands

| Command | Description |
|---|---|
| [build](./build/overview.md) | Build an image from a Dockerfile |
| [history](./history/overview.md) | Show the history of an image |
| [import](./import/overview.md) | Import the contents from a tarball to create a filesystem image |
| [inspect](./inspect/overview.md) | Display detailed information on one or more images |
| [load](./load/overview.md) | Load an image from a tar archive or STDIN |
| [ls](./ls/overview.md) | List images |
| [prune](./prune/overview.md) | Remove unused images |
| [pull](./pull/overview.md) | Download an image from a registry |
| [push](./push/overview.md) | Upload an image to a registry |
| [rm](./rm/overview.md) | Remove one or more images |
| [save](./save/overview.md) | Save one or more images to a tar archive (streamed to STDOUT by default) |
| [tag](./tag/overview.md) | Create a tag TARGET_IMAGE that refers to SOURCE_IMAGE |
