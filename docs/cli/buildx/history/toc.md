# docker buildx history — TOC

Commands to work on build records.

- [Overview](./overview.md)

## Subcommands

| Command | Description |
|---|---|
| [export](./export/overview.md) | Export build records into Docker Desktop bundle |
| [import](./import/overview.md) | Import build records into Docker Desktop |
| [inspect](./inspect/overview.md) | Inspect a build record |
| [logs](./logs/overview.md) | Print the logs of a build record |
| [ls](./ls/overview.md) | List build records |
| [open](./open/overview.md) | Open a build record in Docker Desktop |
| [rm](./rm/overview.md) | Remove build records |
| [trace](./trace/overview.md) | Show the OpenTelemetry trace of a build record |
