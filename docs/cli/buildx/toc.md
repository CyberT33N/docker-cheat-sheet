# docker buildx — TOC

Docker Buildx — extended build capabilities with BuildKit.

- [Overview](./overview.md)

## Subcommands

| Command | Description |
|---|---|
| [bake](./bake/overview.md) | Build from a file |
| [build](./build/overview.md) | Start a build |
| [create](./create/overview.md) | Create a new builder instance |
| [dial-stdio](./dial-stdio/overview.md) | Proxy current stdio streams to builder instance |
| [du](./du/overview.md) | Disk usage |
| [inspect](./inspect/overview.md) | Inspect current builder instance |
| [ls](./ls/overview.md) | List builder instances |
| [prune](./prune/overview.md) | Remove build cache |
| [rm](./rm/overview.md) | Remove one or more builder instances |
| [stop](./stop/overview.md) | Stop builder instance |
| [use](./use/overview.md) | Set the current builder instance |
| [version](./version/overview.md) | Show buildx version information |

## Management command groups

| Command | Description |
|---|---|
| [dap](./dap/toc.md) | Start debug adapter protocol compatible debugger |
| [history](./history/toc.md) | Commands to work on build records |
| [imagetools](./imagetools/toc.md) | Commands to work on images in registry |
| [policy](./policy/toc.md) | Commands for working with build policies |

> Experimental commands and flags are hidden by default. Set `BUILDX_EXPERIMENTAL=1` to show them.
