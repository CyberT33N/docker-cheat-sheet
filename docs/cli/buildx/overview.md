# docker buildx

Docker Buildx — extended build capabilities with BuildKit.

## Usage

```text
docker buildx [OPTIONS] COMMAND
```

## Options

| Option | Description |
|---|---|
| `--builder string` | Override the configured builder instance |
| `-D, --debug` | Enable debug logging |
