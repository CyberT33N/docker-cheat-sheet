# docker service create

Create a new service.

## Usage

```text
docker service create [OPTIONS] IMAGE [COMMAND] [ARG...]
```

## Options

The options are grouped by topic:

- [Compute flags](./flags-compute.md) — resource limits and reservations
- [Networking flags](./flags-networking.md) — DNS, hosts, networks and ports
- [Container flags](./flags-container.md) — environment, health, mounts, secrets and runtime
- [Orchestration flags](./flags-orchestration.md) — placement, replicas, update and rollback policies
