# docker service update

Update a service.

## Usage

```text
docker service update [OPTIONS] SERVICE
```

## Options

The options are grouped by topic. Most options follow the add/rm pattern (`--<name>-add` / `--<name>-rm`):

- [Compute flags](./flags-compute.md) — resource limits and reservations
- [Networking flags](./flags-networking.md) — DNS, hosts, networks and ports
- [Container flags](./flags-container.md) — image, environment, labels, mounts, configs and secrets
- [Runtime flags](./flags-runtime.md) — capabilities, health, security and execution
- [Orchestration flags](./flags-orchestration.md) — placement, replicas, update, rollback and restart policies
