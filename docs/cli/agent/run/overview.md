# docker agent run

Run an agent.

## Usage

```text
docker agent run [<agent-file>|<registry-ref>] [message]...
```

## Options

The options are grouped by topic (plus the [global flags](../overview.md)):

- [Execution flags](./flags-execution.md) — agent selection, models, sandbox, worktree and output
- [Hooks and session flags](./flags-hooks-session.md) — hooks, sessions, recording and environment
