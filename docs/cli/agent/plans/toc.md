| Command | Description |
|---|---|

| [delete](./delete/overview.md) | Delete a shared plan |
| [export](./export/overview.md) | Write a plan's content to a file |
| [get](./get/overview.md) | Print a plan's content and metadata |
| [list](./list/overview.md) | List plans |
| [status](./status/overview.md) | Set the status of an existing shared plan |
| [update](./update/overview.md) | Replace the content of an existing shared plan |
