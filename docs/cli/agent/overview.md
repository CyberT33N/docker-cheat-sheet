# docker agent

Docker AI Agent Runner.

> `docker agent` is a Docker CLI plugin.

## Usage

```text
docker agent [command]
```

## Global Flags

| Option | Description |
|---|---|
| `--cache-dir string` | Override the cache directory |
| `--config-dir string` | Override the config directory |
| `--data-dir string` | Override the data directory |
| `-d, --debug` | Enable debug logging |
| `--log-file string` | Path to debug log file (only used with --debug) |
| `-o, --otel` | Enable OpenTelemetry tracing |
