# docker desktop — TOC

Docker Desktop commands — perform key operations such as starting, stopping, restarting, and updating Docker Desktop directly from the command line.

- [Overview](./overview.md)

## Subcommands

| Command | Description |
|---|---|
| [diagnose](./diagnose/overview.md) | Diagnose Docker Desktop |
| [logs](./logs/overview.md) | Print log entries |
| [restart](./restart/overview.md) | Restart Docker Desktop |
| [start](./start/overview.md) | Start Docker Desktop |
| [status](./status/overview.md) | Show the status of the Docker Desktop engines |
| [stop](./stop/overview.md) | Stop Docker Desktop |
| [update](./update/overview.md) | Manage Docker Desktop updates |
| [version](./version/overview.md) | Show the Docker Desktop CLI plugin version information |
