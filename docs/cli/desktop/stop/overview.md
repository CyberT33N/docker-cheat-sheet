# docker desktop stop

Stop Docker Desktop.

## Usage

```text
docker desktop stop
```

## Options

| Option | Description |
|---|---|
| `-d, --detach` | Do not synchronously wait for the requested operation to complete. |
| `--force` | Force Docker Desktop to stop |
| `--timeout seconds` | Terminate the running command after the specified timeout with a non-zero exit code. A value of zero (the default) or -1 means no timeout. |
