# docker model list

List the models pulled to your local environment.

## Usage

```text
docker model list [OPTIONS] [MODEL]
```

## Aliases

- `docker model ls`

## Options

| Option | Description |
|---|---|
| `--json` | List models in a JSON format |
| `--openai` | List models in an OpenAI format |
| `--openaiurl string` | OpenAI-compatible API endpoint URL to list models from |
| `-q, --quiet` | Only show model IDs |
