# docker node — TOC

Manage Swarm nodes.

- [Overview](./overview.md)

## Subcommands

| Command | Description |
|---|---|
| [demote](./demote/overview.md) | Demote one or more nodes from manager in the swarm |
| [inspect](./inspect/overview.md) | Display detailed information on one or more nodes |
| [ls](./ls/overview.md) | List nodes in the swarm |
| [promote](./promote/overview.md) | Promote one or more nodes to manager in the swarm |
| [ps](./ps/overview.md) | List tasks running on one or more nodes, defaults to current node |
| [rm](./rm/overview.md) | Remove one or more nodes from the swarm |
| [update](./update/overview.md) | Update a node |
