# docker trust revoke

Remove trust for an image. Removes signatures from tags in signed repositories.

- [Docker documentation: docker trust revoke](https://docs.docker.com/reference/cli/docker/trust/revoke/)

## Usage

```text
docker trust revoke [OPTIONS] IMAGE[:TAG]
```

## Options

| Option | Description |
|---|---|
| `-y, --yes` | Do not prompt for confirmation |
