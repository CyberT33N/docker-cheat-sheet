# docker trust signer remove

Remove a signer. Removes signers from signed repositories.

- [Docker documentation: docker trust signer remove](https://docs.docker.com/reference/cli/docker/trust/signer/remove/)

## Usage

```text
docker trust signer remove [OPTIONS] NAME REPOSITORY [REPOSITORY...]
```

## Options

| Option | Description |
|---|---|
| `-f, --force` | Do not prompt for confirmation before removing the most recent signer |
