# docker trust signer add

Add a signer. Adds signers to signed repositories.

- [Docker documentation: docker trust signer add](https://docs.docker.com/reference/cli/docker/trust/signer/add/)

## Usage

```text
docker trust signer add OPTIONS NAME REPOSITORY [REPOSITORY...]
```

## Options

| Option | Description |
|---|---|
| `--key` | Path to the signer's public key file |
