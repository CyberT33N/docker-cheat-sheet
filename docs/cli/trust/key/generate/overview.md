# docker trust key generate

Generate and load a signing key-pair. Generates a key-pair to be used with signing, and loads the private key into the local Docker trust keystore.

- [Docker documentation: docker trust key generate](https://docs.docker.com/reference/cli/docker/trust/key/generate/)

## Usage

```text
docker trust key generate NAME
```

## Options

| Option | Description |
|---|---|
| `--dir` | Directory to generate key in, defaults to current directory |
