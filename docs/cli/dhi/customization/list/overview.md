# docker dhi customization list

List all Docker Hardened Images customizations.

## Usage

```text
docker dhi customization list
```

## Options

| Option | Description |
|---|---|
| `--bulk-id string` | Filter by bulk customization ID (exact match) |
| `-f, --filter string` | Filter by customization name (case-insensitive substring match) |
| `--json` | Output in JSON format |
| `--org string` | Docker Hub organization (overrides config) |
| `-r, --repo string` | Filter by destination repository (case-insensitive substring match) |
| `--source string` | Filter by DHI source repository (case-insensitive substring match) |
