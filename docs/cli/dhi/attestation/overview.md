# docker dhi attestation

Commands to list and inspect attestations attached to Docker Hardened Images.

## Usage

```text
docker dhi attestation [OPTIONS] COMMAND
```

## Aliases

- `docker dhi attest`
- `docker dhi a`

## Options

| Option | Description |
|---|---|
| `--org string` | Docker Hub organization (overrides config) |
