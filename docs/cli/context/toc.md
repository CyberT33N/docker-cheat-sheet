# docker context — TOC

Manage contexts.

- [Overview](./overview.md)

## Subcommands

| Command | Description |
|---|---|
| [create](./create/overview.md) | Create a context |
| [export](./export/overview.md) | Export a context to a tar archive FILE or a tar stream on STDOUT |
| [import](./import/overview.md) | Import a context from a tar or zip file |
| [inspect](./inspect/overview.md) | Display detailed information on one or more contexts |
| [ls](./ls/overview.md) | List contexts |
| [rm](./rm/overview.md) | Remove one or more contexts |
| [show](./show/overview.md) | Print the name of the current context |
| [update](./update/overview.md) | Update a context |
| [use](./use/overview.md) | Set the default docker context |
