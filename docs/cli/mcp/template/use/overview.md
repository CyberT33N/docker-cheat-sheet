# docker mcp template use

Create a profile from a starter template.

## Usage

```text
docker mcp template use <template-id>
```

## Options

| Option | Description |
|---|---|
| `--connect stringArray` | Clients to connect to (can be specified multiple times). Supported clients: claude-code, claude-desktop, cline, codex, continue, crush, cursor, gemini, goose, gordon, kiro, lmstudio, opencode, sema4, vscode, zed |
| `--name string` | Override the profile name (defaults to template title) |
