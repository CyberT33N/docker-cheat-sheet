# docker mcp client — TOC

Manage MCP clients. Supported clients: claude-code, claude-desktop, cline, codex, continue, crush, cursor, gemini, goose, gordon, kiro, lmstudio, opencode, sema4, vscode, zed.

- [Overview](./overview.md)

## Subcommands

| Command | Description |
|---|---|
| [connect](./connect/overview.md) | Connect the Docker MCP Toolkit to a client |
| [disconnect](./disconnect/overview.md) | Disconnect the Docker MCP Toolkit from a client |
| [ls](./ls/overview.md) | List client configurations |
