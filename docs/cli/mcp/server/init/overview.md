# docker mcp server init

Initialize a new MCP server project.

## Usage

```text
docker mcp server init <directory>
```

## Options

| Option | Description |
|---|---|
| `--language string` | Programming language for the server (currently only 'go' is supported) (default "go") |
| `--template string` | Template to use (basic, chatgpt-app-basic) (default "basic") |
