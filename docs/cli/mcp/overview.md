# docker mcp

Docker MCP Toolkit's CLI - Manage your MCP servers and clients.

> `docker mcp` is a Docker CLI plugin.

## Usage

```text
docker mcp [OPTIONS] COMMAND
```

## Options

| Option | Description |
|---|---|
| `-v, --version` | Print version information and quit |
