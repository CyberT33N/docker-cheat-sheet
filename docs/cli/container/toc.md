# docker container — TOC

Manage containers.

- [Overview](./overview.md)

## Subcommands

| Command | Description |
|---|---|
| [attach](./attach/overview.md) | Attach local standard input, output, and error streams to a running container |
| [commit](./commit/overview.md) | Create a new image from a container's changes |
| [cp](./cp/overview.md) | Copy files/folders between a container and the local filesystem |
| [create](./create/overview.md) | Create a new container |
| [diff](./diff/overview.md) | Inspect changes to files or directories on a container's filesystem |
| [exec](./exec/overview.md) | Execute a command in a running container |
| [export](./export/overview.md) | Export a container's filesystem as a tar archive |
| [inspect](./inspect/overview.md) | Display detailed information on one or more containers |
| [kill](./kill/overview.md) | Kill one or more running containers |
| [logs](./logs/overview.md) | Fetch the logs of a container |
| [ls](./ls/overview.md) | List containers |
| [pause](./pause/overview.md) | Pause all processes within one or more containers |
| [port](./port/overview.md) | List port mappings or a specific mapping for the container |
| [prune](./prune/overview.md) | Remove all stopped containers |
| [rename](./rename/overview.md) | Rename a container |
| [restart](./restart/overview.md) | Restart one or more containers |
| [rm](./rm/overview.md) | Remove one or more containers |
| [run](./run/overview.md) | Create and run a new container from an image |
| [start](./start/overview.md) | Start one or more stopped containers |
| [stats](./stats/overview.md) | Display a live stream of container(s) resource usage statistics |
| [stop](./stop/overview.md) | Stop one or more running containers |
| [top](./top/overview.md) | Display the running processes of a container |
| [unpause](./unpause/overview.md) | Unpause all processes within one or more containers |
| [update](./update/overview.md) | Update configuration of one or more containers |
| [wait](./wait/overview.md) | Block until one or more containers stop, then print their exit codes |
