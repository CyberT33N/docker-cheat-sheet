# docker container ls

List containers.

## Usage

```text
docker container ls [OPTIONS]
```

## Aliases

- `docker ps`
- `docker container list`

## Options

Identical to the canonical command. See [docker ps](../../../ps/overview.md) for the complete option reference.

## Documented examples

Show existing containers ([reference](https://docs.docker.com/engine/reference/commandline/container/)):

```bash
sudo docker container -ls
```
