# docker config ls

List configs.

## Usage

```text
docker config ls [OPTIONS]
```

## Aliases

- `docker config list`

## Options

| Option | Description |
|---|---|
| `-f, --filter filter` | Filter output based on conditions provided |
| `--format string` | Format output using a custom template ('table', 'json' or a Go template) |
| `-q, --quiet` | Only display IDs |
