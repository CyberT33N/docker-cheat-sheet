# docker manifest — TOC

Manage Docker image manifests and manifest lists (experimental).

- [Overview](./overview.md)

## Subcommands

| Command | Description |
|---|---|
| [annotate](./annotate/overview.md) | Add additional information to a local image manifest |
| [create](./create/overview.md) | Create a local manifest list for annotating and pushing to a registry |
| [inspect](./inspect/overview.md) | Display an image manifest, or manifest list |
| [push](./push/overview.md) | Push a manifest list to a repository |
| [rm](./rm/overview.md) | Delete one or more manifest lists from local storage |
