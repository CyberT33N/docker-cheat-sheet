# docker manifest

Manage Docker image manifests and manifest lists. A manifest list allows you to use one name to refer to the same image built for multiple architectures.

> EXPERIMENTAL: `docker manifest` is an experimental feature. Experimental features provide early access to product functionality. These features may change between releases without warning, or can be removed from a future release. See [experimental features](https://docs.docker.com/go/experimental/).

## Usage

```text
docker manifest COMMAND
```
