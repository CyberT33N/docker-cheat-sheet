# docker compose — TOC

Docker Compose — define and run multi-container applications with Docker.

- [Overview](./overview.md)

## Subcommands

| Command | Description |
|---|---|
| [attach](./attach/overview.md) | Attach local standard input, output, and error streams to a service's running container |
| [build](./build/overview.md) | Build or rebuild services |
| [commit](./commit/overview.md) | Create a new image from a service container's changes |
| [config](./config/overview.md) | Parse, resolve and render compose file in canonical format |
| [cp](./cp/overview.md) | Copy files/folders between a service container and the local filesystem |
| [create](./create/overview.md) | Creates containers for a service |
| [down](./down/overview.md) | Stop and remove containers, networks |
| [events](./events/overview.md) | Receive real time events from containers |
| [exec](./exec/overview.md) | Execute a command in a running container |
| [export](./export/overview.md) | Export a service container's filesystem as a tar archive |
| [images](./images/overview.md) | List images used by the created containers |
| [kill](./kill/overview.md) | Force stop service containers |
| [logs](./logs/overview.md) | View output from containers |
| [ls](./ls/overview.md) | List running compose projects |
| [pause](./pause/overview.md) | Pause services |
| [port](./port/overview.md) | Print the public port for a port binding |
| [ps](./ps/overview.md) | List containers |
| [publish](./publish/overview.md) | Publish compose application |
| [pull](./pull/overview.md) | Pull service images |
| [push](./push/overview.md) | Push service images |
| [restart](./restart/overview.md) | Restart service containers |
| [rm](./rm/overview.md) | Removes stopped service containers |
| [run](./run/overview.md) | Run a one-off command on a service |
| [scale](./scale/overview.md) | Scale services |
| [start](./start/overview.md) | Start services |
| [stats](./stats/overview.md) | Display a live stream of container(s) resource usage statistics |
| [stop](./stop/overview.md) | Stop services |
| [top](./top/overview.md) | Display the running processes |
| [unpause](./unpause/overview.md) | Unpause services |
| [up](./up/overview.md) | Create and start containers |
| [version](./version/overview.md) | Show the Docker Compose version information |
| [volumes](./volumes/overview.md) | List volumes |
| [wait](./wait/overview.md) | Block until containers of all (or specified) services stop |
| [watch](./watch/overview.md) | Watch build context for service and rebuild/refresh containers when files are updated |
