# docker checkpoint ls

List checkpoints for a container.

> EXPERIMENTAL: This command is experimental and requires a Docker daemon with experimental features enabled.

- [Docker documentation: docker checkpoint ls](https://docs.docker.com/reference/cli/docker/checkpoint/ls/)

## Usage

```text
docker checkpoint ls [OPTIONS] CONTAINER
```

## Aliases

- `docker checkpoint list`

## Options

| Option | Description |
|---|---|
| `--checkpoint-dir` | Use a custom checkpoint storage directory |
