# docker checkpoint rm

Remove a checkpoint.

> EXPERIMENTAL: This command is experimental and requires a Docker daemon with experimental features enabled.

- [Docker documentation: docker checkpoint rm](https://docs.docker.com/reference/cli/docker/checkpoint/rm/)

## Usage

```text
docker checkpoint rm [OPTIONS] CONTAINER CHECKPOINT
```

## Options

| Option | Description |
|---|---|
| `--checkpoint-dir` | Use a custom checkpoint storage directory |
