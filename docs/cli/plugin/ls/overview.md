# docker plugin ls

List plugins.

## Usage

```text
docker plugin ls [OPTIONS]
```

## Aliases

- `docker plugin list`

## Options

| Option | Description |
|---|---|
| `-f, --filter filter` | Provide filter values (e.g. "enabled=true") |
| `--format string` | Format output using a custom template ('table', 'json' or a Go template) |
| `--no-trunc` | Don't truncate output |
| `-q, --quiet` | Only display plugin IDs |
